Pengujian Kinerja Website

Subdomain yang digunakan: https://library.unhas.ac.id/

PageSpeed Insights GTmetrix Lighthouse DevTools DevTools Network/Performance curl TTFB

Tujuan Praktikum

  • Memahami konsep dasar pengujian kinerja website.
  • Mengukur metrik utama (Core Web Vitals dan metrik pendukung).
  • Mengidentifikasi faktor yang memengaruhi kecepatan loading.
  • Membandingkan hasil antar tools.
  • Memberikan rekomendasi sederhana untuk perbaikan performa.

Dasar Teori

Kinerja website memengaruhi UX, SEO, dan bounce rate. Core Web Vitals yang penting:

  • LCP (Largest Contentful Paint): target baik < 2.5 detik.
  • INP (Interaction to Next Paint): target baik < 200 ms.
  • CLS (Cumulative Layout Shift): target baik < 0.1.

Tools umum: Lighthouse, PageSpeed Insights, GTmetrix, dan Chrome DevTools.

Tools

  • Komputer/laptop dengan koneksi internet stabil.
  • Browser Google Chrome terbaru.
  • Akun email (opsional).

Langkah Pengujian Awal

  1. Buka Chrome dan akses https://library.unhas.ac.id/.
  2. Catat waktu dan kondisi jaringan saat pengujian.

Pengujian 1: Google PageSpeed Insights

  1. Buka https://pagespeed.web.dev/.
  2. Masukkan URL: https://library.unhas.ac.id/.
  3. Klik Analyze.
  4. Jalankan untuk Desktop dan Mobile.
  5. Catat:
  • Performance Score (0-100)
  • Core Web Vitals: LCP, INP, CLS

Pengujian 2: GTmetrix

  1. Buka https://gtmetrix.com/.
  2. Masukkan URL: https://library.unhas.ac.id/ lalu klik Test your site.
  3. Tunggu analisis selesai.
  4. Catat:
  • Performance Score dan Structure Score
  • Web Vitals
  • Fully Loaded Time, Total Page Size, Requests
  • Main recommendations

Pengujian 3: Lighthouse di Chrome DevTools

  1. Buka https://library.unhas.ac.id/.
  2. Tekan F12 atau Ctrl+Shift+I, lalu pilih tab Lighthouse.
  3. Atur:
  • Mode: Navigation (default)
  • Device: Desktop dan Mobile (jalankan terpisah)
  • Categories: Performance
  1. Klik Analyze page load.

Pengujian 4: Analisis Manual dengan DevTools

Tab Network

  1. Buka tab Network.
  2. Centang Disable cache dan set Throttling ke Slow 3G atau Fast 3G.
  3. Reload halaman (Ctrl+R).
  4. Catat: TTFB, DOMContentLoaded, Load time, jumlah requests, total size.

Tab Performance

  1. Buka tab Performance.
  2. Klik Record, reload halaman, lalu Stop.
  3. Analisis timeline (FPS, Main Thread, long task).

Analisis dan Pembahasan

  1. Bandingkan hasil antar tools. Mengapa ada perbedaan?
  2. Faktor utama performa rendah (jika ada): gambar besar, JavaScript blocking, render-blocking resources, third-party scripts.
  3. Bandingkan performa mobile vs desktop.
  4. Saran perbaikan realistis: optimasi gambar, lazy loading, CDN, minify CSS/JS.

Pertanyaan

  1. Mengapa Core Web Vitals penting untuk SEO?
  2. Apa yang dimaksud render-blocking resources? Bagaimana cara mengatasinya?
  3. Menurut Anda, apakah performa https://library.unhas.ac.id/ sudah baik? Berikan alasan.

Perintah Tambahan (Opsional)

Jika ingin bukti TTFB dari terminal:

mkdir -p ~/hasil-pengujian
cd ~/hasil-pengujian
echo "===== HASIL CURL / TTFB =====" > hasil-curl.txt
curl -o /dev/null -s -w "TTFB: %{time_starttransfer}s\nDNS Lookup: %{time_namelookup}s\nConnect: %{time_connect}s\nTotal Time: %{time_total}s\nSize Download: %{size_download} bytes\nHTTP Code: %{http_code}\n" https://library.unhas.ac.id/ >> hasil-curl.txt
cat hasil-curl.txt
Jika hasil antar tools berbeda, itu normal karena perbedaan metodologi pengukuran, lokasi server penguji, throttling, dan waktu pengujian.
